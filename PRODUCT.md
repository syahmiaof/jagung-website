# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Rebuild the original's public-evidence stack: Three.js r102, GSAP 2 timelines, and custom full-screen scroll/state control. The reference also used RESN's proprietary Jelly Web3D pipeline, which is not available as a public package. No official source repository was found; the closest public GitHub project is an unlicensed fan remake using a different stack, so it is not the source of this build.

## Users

The project owner, using desktop browsers to practise frontend UI/UX craft and showcase the result. No market audience is defined.

## Product Purpose

A standalone visual playground that rebuilds the desktop experience of Pioneer’s Corn Revolution website as a frontend design and interaction exercise. Success means a visually compelling, enjoyable interactive experience suitable for showing off frontend craft, not sales or lead conversion.

## Capabilities and Constraints

- Build from a new project folder at `ui-jagung`.
- Desktop experience only; no mobile design target was requested.
- Recreate the reference's chapter-based storytelling, full-screen visual scenes, navigation overlay, and interactive condition selection.
- Use Three.js r102 and GSAP 2 for the core 3D and motion approach; recreate the proprietary Jelly pipeline and unavailable 3D assets locally.
- No backend, account flow, or commercial conversion goal was requested.

## Brand Commitments

The user named `https://cornrevolution.resn.global/` as the reference and asked for a close recreation of that website. No separate project name, logo file, or original brand asset was supplied in the workspace.

## Evidence on Hand

- Live desktop reference: `https://cornrevolution.resn.global/`.
- Browser observations from 2026-10-30: fullscreen WebGL scenes, three chapter labels (Science, Real World Testing, Result), hamburger navigation, the Science chapter's library CTA, a condition picker including Wind and Drought, and field-testing story copy.
- Controlled browser replay logs `THREE.WebGLRenderer 102` but stayed at 85% loading in headless capture; this replay is limited and does not establish the reference's normal browser loading behavior.
- Public research found no official source repository. An unrelated fan remake is not original code and has no visible license.
- No source code or local media assets were supplied.

## Product Principles

- Make the visual experience itself the deliverable.
- Keep the chapter journey and its interaction memorable.
- Build the project for desktop frontend experimentation.
- Do not invent a sales funnel or market positioning.
